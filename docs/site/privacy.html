Privacy Policy — Inven Auto Gmail Report Integration

Last updated: November 22, 2026

Information processed

To create and deliver a report, the integration may process automation task statuses, execution timestamps, concise diagnostic messages, links to GitHub Issues and Actions runs, the configured recipient email address, and OAuth credentials needed to send email.

Google permissions and use

The integration requests only the Google OAuth scope https://www.googleapis.com/auth/gmail.send. This permission is used to send report emails. The integration is not designed to read, search, label, modify, or delete Gmail messages.

OAuth access tokens are obtained when needed. The refresh token and OAuth client credentials are stored as GitHub Actions repository secrets, not in source code.

Storage and sharing

The integration does not sell personal information or use report data for advertising. GitHub may process and retain automation data and logs as part of GitHub Actions and Issues. Google processes email delivery through Gmail. These services are subject to their own terms and privacy practices.

No data is intentionally shared with unrelated third parties by this integration.

Retention and deletion

The project owner can remove GitHub Actions secrets, delete relevant workflow artifacts or issues, and revoke the Google OAuth grant. Copies already delivered to an inbox are controlled by the recipient and their email provider.

Security

OAuth secrets should be stored only as GitHub Actions secrets and must never be committed to the repository or posted publicly. Repository access should be limited to authorized users.

Changes

This policy may be updated if the integration's data handling or requested permissions change.

Contact

For questions about this policy, contact the project owner through the Inven Auto GitHub issue tracker.
