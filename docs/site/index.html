Inven Auto — Gmail Report Integration

Inven Auto runs scheduled personal automation tasks and records their results in GitHub Actions and GitHub Issues. Its optional Gmail integration sends a daily status report to the recipient configured by the project owner.

What the report contains

Task outcomes, execution timestamps, concise diagnostic information, and links to the relevant GitHub issue, workflow run, and job logs.

Google account access

The integration requests only the https://www.googleapis.com/auth/gmail.send OAuth permission. It uses this permission to send report messages. It is not designed to read, search, modify, or delete mailbox messages.

Control and security

The integration is intended for the project owner's personal use. OAuth client credentials and refresh tokens are stored as GitHub Actions secrets rather than committed to source code. The owner can stop delivery by removing those secrets or revoking the Google account grant.

See the Privacy Policy for details about information handling.
